# BPMN MIWG reference models

These 21 files are reference models of the OMG BPMN Model Interchange Working
Group (MIWG), copied unchanged from the `Reference` folder of
https://github.com/bpmn-miwg/bpmn-miwg-test-suite (retrieved 2 November 2026).

They are licensed under the Creative Commons Attribution 3.0 Unported License
(https://creativecommons.org/licenses/by/3.0/) by the BPMN MIWG and its
contributors. They are included here only as a test set for the validation;
model C.1.0 is missing because it could not be retrieved.

Result with this draft: `python validate.py corpus/miwg/*.bpmn` gives
0 violations and 5 warnings (activities without a name in C.9.0 and C.9.2).
